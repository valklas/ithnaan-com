# ITHNAAN

Visit [ithnaan](https://ithnaan.com).

# Development

To install packages:
```bash
bun install
```

To run the server:
```bash
npx wrangler dev
```

# Deploy

To deploy to cloudflare:
```bash
npx wrangler deploy
```
